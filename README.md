## Установка и запуск локально

```bash
# 1. Клонировать репозиторий
git clone <ссылка на репозиторий>

# 2. Установить зависимости
npm install

# 3. Запустить проект
npm run dev
```

Для просмотра страницы откройте http://localhost:5173 после запуска.

## Ключевые решения
- **Хэдер, футер и фон секции hero** — сделаны на всю ширину экрана осознано, чтобы на экранах шире 1440px (ограничение макета) страница выглядела полноценно и не обрывалась по бокам. Контент при этом остаётся в центре, ограниченный контейнером. 
- **Анимация стрелок вниз** — реализована на CSS (`@keyframes`) без JS, чтобы снизить нагрузку на основной поток и не создавать лишних обработчиков.
- **SVG-спрайт** — используется для иконок, чтобы уменьшить количество HTTP-запросов и упростить поддержку.
- **Изображения** — экспортированы и сжаты без потери качества (PNG, JPG), чтобы ускорить загрузку страницы.

## Реализовано
- Адаптивная (резиновая) вёрстка (desktop 1024+, tablet 768+, mobile 360+)
- Подход mobile-first
- Бургер-меню с анимацией
- Форма поиска с календарём (flatpickr) и обработкой без отправки
- Слайдер отзывов
- Анимация стрелок вниз на CSS (без JS)
- Выпадающие списки (валюты, язык, контакты)
- Плавный скролл к секциям
- Hover/focus-состояния для всех интерактивных элементов
- Семантическая структура (header, main, section, footer)
- БЭМ-именование классов
- Модульная структура JS
